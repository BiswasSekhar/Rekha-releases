# Rekha release notes

## 1.2.2

- Improved PDF chat with Gemini 3.1 Flash-Lite, bounded ten-page context, summaries, and follow-up suggestion chips.
- Added selected-page PDF fallback when OCR or text extraction fails, including Indic-language documents.
- Improved reader gestures, page thumbnails, split/merge/reorder previews, and dark-theme consistency.
- Added update notifications and the public-release download flow for signed Android builds.
- Added safer chat history, export, entitlement, and background-task handling.

Older builds and their checksums are available from the [Releases page](https://github.com/BiswasSekhar/Rekha-releases/releases).
